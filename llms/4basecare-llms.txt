# 4baseCare

> Precision oncology company (founded 2018; Bengaluru, India and Singapore) combining
> next-generation-sequencing comprehensive genomic profiling with AI-driven clinical
> decision support to personalize cancer treatment. As of a 2026-09-05 probe, 4baseCare
> publishes no public API, no developer program and no machine-readable API contract.
> This file is generated by API Evangelist from the public company record; it is not
> published by 4baseCare.

## Products

- [Genomic Tests](https://www.4basecare.com/genomic-tests): TARGT comprehensive genomic
  profiling panels - solid biopsy (TARGT First, First Lite, Indiegene, Indiegene PRO,
  Absolute Plus), liquid biopsy (First Liquid, Indiegene Liquid), dual-source SoLiQ
  (First SoLiQ, Indiegene SoLiQ, Absolute SoLiQ), plus HRD PARPredict and Germline+.
- [OncoTwin](https://www.4basecare.com/oncotwin-insights): AI clinical decision support layer.
- [GCDA](https://www.4basecare.com/gcda): Global Cancer Diversity Atlas, 30,000+ genomic profiles.
- [Molecular Tumor Board](https://www.4basecare.com/molecular-tumor-board): MTB decision support.
- [Oncobuddy](https://www.4basecare.com/oncobuddy): patient support program.

## Portals

- [Galens](https://galens.4basecare.com/): clinician-facing precision oncology web portal.
  Login-gated single-page app. Its private backend is api.4basecare.com, which is an
  undocumented application backend, not a developer API.
